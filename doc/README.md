# lib.scad.clamps documentation

This directory is the maintained engineering-documentation index for
`lib.scad.clamps`.

The library provides reusable parametric clamp designs. OpenSCAD is the primary
implementation direction; PythonSCAD remains a maintained comparison and
regression path.
