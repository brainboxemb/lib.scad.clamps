# lib.scad.clamps user manual

## OpenSCAD

The primary reusable API is object-based:

```scad
clamp = tube_clamp_create(...);
tube_clamp_build(clamp);
tube_clamp_render(clamp, view = TUBE_CLAMP_VIEW_OPENING);
```

## PythonSCAD

The maintained comparison implementation uses native Python OOP:

```python
clamp = TubeClamp(...)
clamp.build()
clamp.render(view=TubeClamp.View.OPENING)
```

Equivalent design behavior is the goal; syntax-level symmetry is not required.

## Design guidance

For exact construction rationale and visual steps, use the component-local
design documents:

- [OpenSCAD tube-clamp design](../openscad/tube-clamp/design/design.md)
- [PythonSCAD tube-clamp design](../pythonscad/tube-clamp/design/design.md)

The library owns reusable clamp geometry. Product-specific mounting, placement
and surrounding-body decisions remain with consuming repositories.
